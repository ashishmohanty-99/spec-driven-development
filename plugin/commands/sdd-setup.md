Invoke the `guided-setup` skill.

Summarise what the tool detected in plain language, run `sdd questions --json`, and ask the open questions one at a time with the recommended option first. Record each answer with `sdd answer`. For the lifecycle question, state the consequence of skipping any check and record the person's reason with `sdd lifecycle skip`. Finish with the next action from `sdd next`.
